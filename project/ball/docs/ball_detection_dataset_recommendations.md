# 钢球检测数据集：现状与优化建议

## 当前数据概况

`project/ball/dataset` 中的图片已进行人工筛选和清洗，检测类别统一为 `gangqiu`。当前数据按来源独立保存，并已使用连续编号：

| 数据集 | 图片 / XML | 标注框数 | 平均标注框数 | 单图最多标注框 | 当前状态 |
| --- | ---: | ---: | ---: | --- | --- |
| `dataset_xzh` | 58 / 58 | 899 | 15.5 | 70（`x000037.jpg`） | 已标注 |
| `dataset_ywq` | 97 / 97 | 574 | 5.9 | 34（`y000018.jpg`） | 已标注 |
| `dataset_zhn` | 208 / 0 | — | — | — | 已清洗，待标注 |
| **已标注合计** | **155 / 155** | **1,473** | **9.5** | — | 可在完善元数据后用于训练 |

- `dataset_xzh` 的图片和 XML 为 `x000001` 至 `x000058`，目标相对更密集。
- `dataset_ywq` 的图片和 XML 为 `y000001` 至 `y000097`，目标相对更稀疏。
- `dataset_zhn` 的图片为 `z000001` 至 `z000208`；当前仅包含 `images/`，尚未创建 Pascal VOC 的 `xml/` 和 `labels.txt`。

## 已发现的注意事项

1. 已标注的两组数据中，全部 155 个 XML 都缺少 Pascal VOC 的 `<size>` 节点。虽然边界框坐标已存在，但图片宽高与深度元数据不完整；转换、训练或上传前应按每张原图补齐。
2. `dataset_xzh` 的密集样本占比较高，单张最多 70 个目标；`dataset_ywq` 则更偏向少目标场景。训练时应避免仅由密集图或稀疏图主导。
3. `dataset_zhn` 是新增的清洗图片，但没有标注文件，不能直接与前两组一起按 Pascal VOC 格式上传或训练。
4. 若数据中包含包装、宣传文字、印刷钢球图案、强反光或遮挡，应统一“哪些钢球算检测目标”的标注规则，避免同类视觉内容出现相互矛盾的标注。

## 建议的处理顺序

### 1. 补齐 VOC 元数据并复核已标注集

- 为 `dataset_xzh` 和 `dataset_ywq` 的每个 XML 补充 `<size>`，其中 `width`、`height` 应与对应图片真实尺寸一致，`depth` 应与图片通道数一致。
- 补齐后检查每个边界框是否落在图片范围内，以及 `xmin < xmax`、`ymin < ymax` 是否成立。
- 优先抽检高密度图（如 `x000037.jpg`）、小目标、强反光和遮挡样本，检查漏标、重复框和框偏移。

### 2. 标注新增的 `dataset_zhn`

- 建立 `dataset_zhn/xml/`，为 208 张 `z` 前缀图片创建同名 XML；建立 `labels.txt`，内容为单行 `gangqiu`。
- 标注时沿用前两组相同的类别名、坐标规范与目标判定规则。
- 标注完成后，重新统计图片数、标注框数、单图最大框数，并抽检图片/XML 是否一一对应。

### 3. 统一标注规则

在继续标注或增强前，明确并统一以下规则：

- 包装或宣传海报中印刷的钢球是否标注？
- 只露出一部分的遮挡钢球是否标注？
- 极小、难以确认的钢球是否标注？
- 不同直径的钢球是否都使用同一个 `gangqiu` 类别？

所有数据集和后续新增图片都必须执行同一套规则。

### 4. 平衡训练与验证数据

- 合并训练时保留数据来源标识，分层抽取 `x`、`y`、`z` 三类来源，避免训练集被密集场景或稀疏场景单独主导。
- 按拍摄场景、商品来源或拍摄批次切分训练集与验证集，而不是只做随机切分，以避免近似图片同时落入两侧。
- 单独保留一组不参与训练的最终部署场景图片作为测试集，作为模型效果的主要依据。

### 5. 补充真实场景与负样本

提升最终识别准确率最有效的方法，是用最终部署环境采集数据。应尽量覆盖：

- 最终相机、实际拍摄距离与角度；
- 实际背景、光照、反光和阴影；
- 少球、多球、堆叠、遮挡和不同尺寸；
- 轻微失焦、运动模糊和曝光变化；
- 不含钢球的负样本，以及螺丝、螺母、轴承、金属零件、反光圆形物体和空容器等易混淆物体。

### 6. 数据增强策略

优先使用贴近真实拍摄条件的增强：

- 亮度、对比度、色温和曝光变化；
- 轻微高斯模糊或运动模糊；
- 缩放、裁剪和轻微透视变化；
- 局部遮挡；
- 背景与反光变化。

避免只依赖拼贴或过强的合成增强，以免模型进一步偏向特定来源图片的视觉风格。
