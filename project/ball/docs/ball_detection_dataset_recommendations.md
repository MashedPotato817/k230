# 钢球检测数据集：抽样诊断与优化建议

## 当前数据概况

- `dataset_xzh`：95 张图片、3,229 个钢球标注，平均约 34 个/图；样本明显偏向密集堆叠场景。
- `dataset_ywq`：99 张图片、592 个钢球标注，平均约 6 个/图；样本更偏向少量钢球、手持和白底产品图。
- 两份数据集的类别名称已统一为 `gangqiu`，并保持分开，方便后续选择性合并或增强。

抽样图片以电商产品图为主，包括白底、宣传文字、包装盒、手持钢球和密集堆叠钢球。这些图可帮助模型识别钢球外观，但若最终部署在固定摄像头、传送带、实验台或其他真实拍摄环境，会存在明显的场景差异。

## 已发现的注意事项

1. `dataset_ywq` 的 XML 中，`<size>` 下的 `width` 与 `height` 当前为 `0`。边界框坐标可能仍然正确，但 Pascal VOC 元数据不完整；上传或训练前应更新为每张原图的实际尺寸。
2. `dataset_xzh` 的密集样本数量和单图目标数都较高。若部署场景大多只有少量钢球，训练应避免让密集图占据过强影响。
3. 电商宣传图含有文字、Logo、包装、拼图或印刷钢球图案。需要统一“哪些钢球算检测目标”的标注规则，避免同类视觉内容出现相互矛盾的标注。

## 建议的处理顺序

### 1. 完善标注元数据与抽检标注质量

- 将 `dataset_ywq` 所有 XML 的图片宽度、高度补为真实值。
- 优先抽检高密度图、极小钢球图、包装/海报图和强反光图。
- 检查是否存在漏标、重叠框、框偏移，尤其是相互遮挡的钢球。

### 2. 统一标注规则

在继续标注或增强前，明确并统一以下规则：

- 包装或宣传海报中印刷的钢球是否标注？
- 只露出一部分的遮挡钢球是否标注？
- 极小、难以确认的钢球是否标注？
- 不同直径的钢球是否都使用同一个 `gangqiu` 类别？

两份数据集和后续新增数据必须执行同一套规则。

### 3. 补充目标场景数据（最重要）

提升最终识别准确率最有效的方法，是用最终部署环境采集数据。应尽量覆盖：

- 最终相机或手机、实际拍摄距离与角度；
- 实际背景、光照、反光和阴影；
- 少球、多球、堆叠、遮挡和不同尺寸；
- 轻微失焦、运动模糊和曝光变化。

如果最终使用固定摄像头，应优先采集固定摄像头画面，而不是继续主要依赖电商图片。

### 4. 加入负样本

采集不含钢球的图片，以及容易混淆的物体，例如螺丝、螺母、轴承、金属零件、反光圆形物体和空容器。负样本可降低模型误检。

### 5. 数据增强策略

优先使用贴近真实拍摄条件的增强：

- 亮度、对比度、色温和曝光变化；
- 轻微高斯模糊或运动模糊；
- 缩放、裁剪和轻微透视变化；
- 局部遮挡；
- 背景与反光变化。

避免只依赖拼贴或过强的合成增强，以免模型进一步偏向电商图风格。

### 6. 合理评估模型

训练集与验证集应按拍摄场景、商品来源或拍摄批次分组切分，而不是简单随机切分。这样可避免近似图片同时落入训练集和验证集，导致验证准确率虚高。

另应单独准备一组来自最终部署场景、完全不参与训练的测试集，作为最终模型效果依据。
