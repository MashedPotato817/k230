## 已发现的注意事项

1. 训练网站不要求 XML 的 `<size>` 元数据，且会自动按 8:1:1 划分训练、验证和测试集，因此当前无需为此补充元数据或手动切分。
2. `dataset_xzh` 的密集样本占比较高，单张最多 50 个目标；`dataset_ywq` 则更偏向少目标场景。训练时应避免仅由密集图或稀疏图主导。
3. 增强集已不使用旋转。上传前应抽检 `_a03` 的边界框变换及 `m000001` 至 `m000030` 的 Mosaic 标注框。
4. `dataset_zhn` 是新增的清洗图片，但没有标注文件，不能直接与前两组一起按 Pascal VOC 格式上传或训练。

## 建议的处理顺序

### 1. 复核增强标注

- 随机抽检 `_a03` 的缩放、平移和透视后的边界框，以及 30 张 Mosaic 的拼接边界框。
- 检查边界框是否落在图片范围内，以及 `xmin < xmax`、`ymin < ymax` 是否成立。
- 优先抽检高密度图（如 `x000023.jpg`）、小目标、强反光和遮挡样本，检查漏标、重复框和框偏移。

### 2. 标注新增的 `dataset_zhn`

- 建立 `dataset_zhn/xml/`，为 208 张 `z` 前缀图片创建同名 XML；建立 `labels.txt`，内容为单行 `gangqiu`。
- 标注时沿用前两组相同的类别名、坐标规范与目标判定规则。
- 标注完成后，重新统计图片数、标注框数、单图最大框数，并抽检图片/XML 是否一一对应。

### 3. 统一标注规则

在继续标注或增强前，明确并统一以下规则：

- 包装或宣传海报中印刷的钢球是否标注？
- 只露出一部分的遮挡钢球是否标注？
- 极小、难以确认的钢球是否标注？
- 不同直径的钢球是否都使用同一个 `gangqiu` 类别？

所有数据集和后续新增图片都必须执行同一套规则。

### 4. 使用训练网站自动划分

- 上传数据集后由训练网站按 8:1:1 自动划分训练、验证和测试集，无需本地手动切分。
- 模型完成训练后，仍可用未参与训练的真实部署画面补充检查密集、反光和遮挡场景的表现。

### 5. 补充真实场景与负样本

提升最终识别准确率最有效的方法，是用最终部署环境采集数据。应尽量覆盖：

- 最终相机、实际拍摄距离与角度；
- 实际背景、光照、反光和阴影；
- 少球、多球、堆叠、遮挡和不同尺寸；
- 轻微失焦、运动模糊和曝光变化；
- 不含钢球的负样本，以及螺丝、螺母、轴承、金属零件、反光圆形物体和空容器等易混淆物体。

### 6. 数据增强策略

优先使用贴近真实拍摄条件的增强：

- 亮度、对比度、色温和曝光变化；
- 轻微高斯模糊或运动模糊；
- 无旋转的缩放、平移和轻微透视变化；
- 局部遮挡；
- 背景与反光变化。

避免只依赖拼贴或过强的合成增强，以免模型进一步偏向特定来源图片的视觉风格。
