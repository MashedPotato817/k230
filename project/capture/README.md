# 超广角摄像头拍照

使用 K230D BOX 的 J2 / CSI1 超广角摄像头预览画面，并通过 K0 按键拍照。

## 入口与行为

- 入口：[`main.py`](main.py)
- 摄像头：CSI1（`Sensor(id=1)`）
- 预览：640 × 480 LCD / IDE 画面
- 拍照：K0（GPIO34）按下时保存一张高分辨率照片
- 保存位置：开发板 `/data/pic/wide_<时间戳>.jpg`

## 运行

将 `main.py` 上传到开发板后运行。首次运行会自动创建 `/data/pic`；请确认开发板的数据分区有可用空间。

此项目面向连接在 J2 接口的超广角摄像头，不适用于默认 CSI0 摄像头配置。
